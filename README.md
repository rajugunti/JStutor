# JSTutor

JSTutor is a JavaScript interview typing practice website that helps users improve their typing speed and accuracy while preparing for interviews.

## Technologies Used
- React
- JavaScript
- Python
- Django REST Framework
- MySQL

## Features
- Practice JavaScript interview questions
- Type answers directly in the typing area
- Navigate between questions
- Track typing speed and accuracy
